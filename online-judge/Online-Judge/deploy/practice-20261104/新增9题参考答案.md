## 202611040001 · 有序数组去重计数

给定按非递减顺序排列的整数数组 nums，返回其中不同整数的个数。无需修改数组。

**约束：** 1 ≤ nums.length ≤ 200000；-10^9 ≤ nums[i] ≤ 10^9。

```text
nums = [1,1,2,2,3] → 3
nums = [-2,-2,-2] → 1
```

**解题思路：** 有序数组中相同元素必然相邻。先计入第一个元素，再统计与前一个值不同的位置。

**正确性：** 每个不同值恰好形成一个连续分组；首元素和每次值变化分别对应一个分组的开始，因此计数等于不同值个数。

**复杂度：** 时间 O(n)，额外空间 O(1)。

```java
public class Solution {
    public static int countDistinct(int[] nums) {
        int count = 1;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[i - 1]) count++;
        }
        return count;
    }
}
```

## 202611040002 · 一次买卖的最大收益

prices[i] 表示第 i 天的价格。最多买入并卖出一次，且买入日必须早于卖出日。返回最大收益；可以不交易，此时收益为 0。

**约束：** 1 ≤ prices.length ≤ 200000；0 ≤ prices[i] ≤ 10^9。

```text
prices = [7,1,5,3,6,4] → 5
prices = [7,6,4,3,1] → 0
```

**解题思路：** 顺序扫描，维护已遇到的最低价格，以当前价格减去最低价格更新最大收益。

**正确性：** 对每个卖出日，之前最低价格对应当天能获得的最优收益；遍历所有卖出日后得到全局最优。收益初始为 0，涵盖不交易的情况。

**复杂度：** 时间 O(n)，额外空间 O(1)。

```java
public class Solution {
    public static int maxProfit(int[] prices) {
        int low = prices[0], best = 0;
        for (int price : prices) {
            best = Math.max(best, price - low);
            low = Math.min(low, price);
        }
        return best;
    }
}
```

## 202611040003 · 括号序列校验

字符串 s 仅含 ()[]{}。判断所有括号能否按类型正确配对，且嵌套顺序正确。返回 true 或 false。

**约束：** 1 ≤ s.length ≤ 200000。

```text
s = "([]{})" → true
s = "([)]" → false
```

**解题思路：** 用字符栈存储尚未匹配的左括号。遇到右括号时，只能与栈顶的对应左括号配对。

**正确性：** 栈始终按出现顺序保存未闭合的左括号。合法嵌套要求最后出现的左括号最先闭合，因此栈顶不匹配时必定非法；扫描结束栈空则全部正确配对。

**复杂度：** 时间 O(n)，额外空间 O(n)。

```java
public class Solution {
    public static boolean isValid(String s) {
        char[] stack = new char[s.length()];
        int top = 0;
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') stack[top++] = c;
            else {
                char want = c == ')' ? '(' : c == ']' ? '[' : '{';
                if (top == 0 || stack[--top] != want) return false;
            }
        }
        return top == 0;
    }
}
```

## 202611040004 · 和为目标值的连续子数组

给定整数数组 nums 和整数 k，返回元素和恰好等于 k 的非空连续子数组个数。元素可能为负数，返回值使用 long。

**约束：** 1 ≤ nums.length ≤ 200000；-10^9 ≤ nums[i], k ≤ 10^9。

```text
nums = [1,1,1], k = 2 → 2
nums = [0,0,0], k = 0 → 6
```

**解题思路：** 维护 long 前缀和及其出现次数。当前前缀和为 sum 时，之前值为 sum-k 的每个前缀都对应一个满足要求的子数组。先查询再登记当前前缀。

**正确性：** 子数组 [l,r) 的和等于 prefix[r]-prefix[l]。计数表只保存 r 之前的前缀，所以恰好统计所有非空合法子数组且不会重复。初始登记前缀 0，涵盖从首元素开始的子数组。

**复杂度：** 期望时间 O(n)，额外空间 O(n)。前缀和与答案都使用 long。

```java
public class Solution {
    public static long countSubarrays(int[] nums, int k) {
        java.util.Map<Long, Long> counts = new java.util.HashMap<>();
        counts.put(0L, 1L);
        long sum = 0, answer = 0;
        for (int value : nums) {
            sum += value;
            answer += counts.getOrDefault(sum - k, 0L);
            counts.put(sum, counts.getOrDefault(sum, 0L) + 1);
        }
        return answer;
    }
}
```

## 202611040005 · 最长严格递增子序列

从 nums 中按原顺序选择若干元素，要求后一个元素严格大于前一个元素。返回能选出的最长子序列长度；所选元素无需连续。

**约束：** 1 ≤ nums.length ≤ 200000；-10^9 ≤ nums[i] ≤ 10^9；要求 O(n log n) 时间。

```text
nums = [10,9,2,5,3,7,101,18] → 4
nums = [2,2,2] → 1
```

**解题思路：** tails[i] 维护长度为 i+1 的递增子序列能取得的最小尾值。对每个元素二分查找第一个大于等于它的位置并替换；找不到则扩展长度。

**正确性：** 更小的尾值不会减少未来可接入的元素。二分得到的位置前面均小于当前值，故可构造对应长度的严格递增子序列；替换保持最小尾值不变量。最终 tails 的有效长度即最优长度。

**复杂度：** 时间 O(n log n)，额外空间 O(n)。使用 lower_bound，重复元素不会扩展长度。

```java
public class Solution {
    public static int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;
        for (int x : nums) {
            int lo = 0, hi = size;
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (tails[mid] < x) lo = mid + 1;
                else hi = mid;
            }
            tails[lo] = x;
            if (lo == size) size++;
        }
        return size;
    }
}
```

## 202611040006 · 凑出金额的最少硬币数

coins 给出各类硬币的正整数面值，每类数量无限。返回恰好凑出 amount 所需的最少硬币数；无法凑出返回 -1；amount 为 0 时返回 0。

**约束：** 1 ≤ coins.length ≤ 100；1 ≤ coins[i] ≤ 10000；0 ≤ amount ≤ 10000。允许重复面值。

```text
coins = [1,2,5], amount = 11 → 3
coins = [2], amount = 3 → -1
```

**解题思路：** 令 dp[s] 为凑出金额 s 所需的最少硬币数，dp[0]=0。按金额递增遍历，枚举最后使用的硬币 c，以 dp[s-c]+1 更新。

**正确性：** 任意正金额的最优方案都有最后一枚硬币，去掉它后必须是剩余金额的最优方案。所有面值均为正，因此依赖金额更小，递增顺序可以求出完整最优解。

**复杂度：** 时间 O(amount × coins.length)，额外空间 O(amount)。

```java
public class Solution {
    public static int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];
        java.util.Arrays.fill(dp, amount + 1);
        dp[0] = 0;
        for (int s = 1; s <= amount; s++) {
            for (int c : coins) {
                if (c <= s) dp[s] = Math.min(dp[s], dp[s - c] + 1);
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

## 202611040007 · 雨后蓄水总量

height 表示一排宽度均为 1 的柱子高度。下雨后，返回柱子之间能够积存的水量。水不会从两端外侧积存，返回值使用 long。

**约束：** 1 ≤ height.length ≤ 200000；0 ≤ height[i] ≤ 10^9；要求 O(n) 时间及 O(1) 额外空间。

```text
height = [0,1,0,2,1,0,1,3,2,1,2,1] → 6
height = [3,0,3] → 3
```

**解题思路：** 使用左右指针以及左右已扫描区域的最大高度。每次处理当前较矮的一端：另一端已提供足够高的边界，可以直接累加本端最大高度与当前柱高的差。

**正确性：** 处理左端时若左侧历史最高柱超过当前右端，则该最高柱出现时右侧已有不低于它的边界，否则算法会先移动右端而不会越过该左柱。因此较矮端的历史最高值能作为有效水位；右端同理。每个位置恰好处理一次。

**复杂度：** 时间 O(n)，额外空间 O(1)。累加水量使用 long，防止溢出。

```java
public class Solution {
    public static long trap(int[] height) {
        int left = 0, right = height.length - 1;
        int leftMax = 0, rightMax = 0;
        long answer = 0;
        while (left <= right) {
            if (height[left] <= height[right]) {
                leftMax = Math.max(leftMax, height[left]);
                answer += leftMax - height[left++];
            } else {
                rightMax = Math.max(rightMax, height[right]);
                answer += rightMax - height[right--];
            }
        }
        return answer;
    }
}
```

## 202611040008 · 柱状图中的最大矩形

heights 表示一排相邻柱子的高度，每根宽度为 1。选择连续若干根柱子，在它们覆盖的区间内找出完全位于柱状图内部的最大矩形面积，返回 long。

**约束：** 1 ≤ heights.length ≤ 200000；0 ≤ heights[i] ≤ 10^9；要求 O(n) 时间。

```text
heights = [2,1,5,6,2,3] → 10
heights = [2,2,2] → 6
```

**解题思路：** 维护高度非递减的下标栈。遇到较矮柱子时，逐个弹出更高的柱子，以弹出柱高为矩形高度、当前下标为右开边界、弹出后的栈顶为左开边界计算面积。末尾补一个高度 0。

**正确性：** 弹出时，当前柱子是右侧第一个更矮边界；栈顶与当前下标之间的柱子均不低于弹出高度。等高柱子可能暂时限制左边界，但最左侧同高柱最终会枚举完整宽度。因此必然枚举到最优矩形，且所有计算出的矩形均合法。

**复杂度：** 时间 O(n)，额外空间 O(n)。先将高度转为 long 再乘宽度。

```java
public class Solution {
    public static long largestRectangleArea(int[] heights) {
        int n = heights.length, top = 0;
        int[] stack = new int[n];
        long best = 0;
        for (int i = 0; i <= n; i++) {
            int current = i == n ? 0 : heights[i];
            while (top > 0 && heights[stack[top - 1]] > current) {
                int h = heights[stack[--top]];
                int left = top == 0 ? -1 : stack[top - 1];
                best = Math.max(best, (long) h * (i - left - 1));
            }
            if (i < n) stack[top++] = i;
        }
        return best;
    }
}
```

## 202611040009 · 含负数数组的最短达标区间

给定可能含负数的整数数组 nums 和正整数 k，返回元素和大于等于 k 的最短非空连续子数组长度；不存在则返回 -1。

**约束：** 1 ≤ nums.length ≤ 200000；-10^9 ≤ nums[i] ≤ 10^9；1 ≤ k ≤ 10^9；要求 O(n) 时间。

```text
nums = [2,-1,2], k = 3 → 3
nums = [84,-37,32,40,95], k = 167 → 3
```

**解题思路：** 计算 long 前缀和，维护前缀值严格递增的下标双端队列。当前前缀与队首的差达到 k 时更新答案并弹出队首；当前前缀不大于队尾时弹出队尾，最后加入当前下标。

**正确性：** 已达标的队首在未来只会得到更长区间，可以删除。如果较新的前缀和不大于较旧前缀和，则它对所有未来右端都能得到至少同样大的区间和且长度更短，旧下标可被永久淘汰。保留下标因此覆盖所有可能的最优解。

**复杂度：** 时间 O(n)，额外空间 O(n)。每个下标最多入队一次、出队一次；前缀和使用 long。

```java
public class Solution {
    public static int shortestSubarray(int[] nums, int k) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + nums[i];
        int[] deque = new int[n + 1];
        int head = 0, tail = 0, best = n + 1;
        for (int i = 0; i <= n; i++) {
            while (head < tail && prefix[i] - prefix[deque[head]] >= k) {
                best = Math.min(best, i - deque[head++]);
            }
            while (head < tail && prefix[deque[tail - 1]] >= prefix[i]) tail--;
            deque[tail++] = i;
        }
        return best == n + 1 ? -1 : best;
    }
}
```
